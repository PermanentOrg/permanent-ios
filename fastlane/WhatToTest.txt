This build hardens file permissions: the app now understands the backend's new access-role format, so an owner can never be silently downgraded to viewer when the backend switches formats.

Please focus on:

1. On an archive you own, open Private Files. The + button must be there. Create a folder and upload a photo — both must work. The three-dot menu on a file must offer rename, move, copy, delete and share.

2. Switch to an archive where you are Viewer (gear icon, then My archives). Private Files must show no + button, and the three-dot menu on items must stay read-only.

3. On the My archives screen, the access label under every archive must be correct: Owner, Viewer, and so on.

4. In Shared Files, open something shared to you. The role badge in the item menu must match what was granted, and you must only be able to do what that role allows.

Nothing else changed in this build, but a quick smoke pass over uploads and navigation is welcome, since it ships on top of 1.16.0.
